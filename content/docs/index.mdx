Qeet ID is an open-source, self-hostable identity platform: **passkeys-first**
authentication, explainable authorization, first-class SSO/SCIM, and a
tamper-evident audit log — with no per-MAU fee and no SSO tax.

This portal is the developer documentation. The complete **API reference** lives
separately in Scalar and is linked from the top navigation.

<Callout title="Developer preview">
  Qeet ID is under active development. These docs are built out section by
  section — start with the quickstart, then explore the concepts.
</Callout>
