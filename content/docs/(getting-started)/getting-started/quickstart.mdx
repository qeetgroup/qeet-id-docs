This quickstart takes a Go service from an empty project to a verified session
and an authorization check. The Go module is the executable preview path while
the Node and React packages await their first npm release.

<Callout type="info">
  You'll need a Qeet ID application, an API key, and a session access token from
  your hosted login flow. Create the application in the console, then set
  `QEETID_API_KEY` and `QEETID_BASE_URL` before you begin.
</Callout>

## 1. Install the Go SDK

```bash title="Terminal"
go get github.com/qeetgroup/qeet-id-go
```

## 2. Initialize the client

Create a single client instance and reuse it across requests.

```go title="qeetid.go"
client := qeetid.New(qeetid.Config{
  APIKey:  os.Getenv("QEETID_API_KEY"),
  BaseURL: os.Getenv("QEETID_BASE_URL"),
})
```

## 3. Verify the session and authorize

Read the bearer token from the request, verify it locally against cached JWKS,
then ask an authorization question using the tenant carried by the token.

```go title="handler.go"
claims, err := client.Sessions.Verify(ctx, token)
if err != nil {
  return fmt.Errorf("verify session: %w", err)
}

allowed, err := client.Permissions.Check(ctx, qeetid.PermissionCheck{
  User:       claims.UserID,
  Tenant:     claims.TenantID,
  Permission: "billing:write",
})
if err != nil {
  return fmt.Errorf("check permission: %w", err)
}

if !allowed {
  return errors.New("forbidden")
}
```

<Callout type="success">
  The request now has a cryptographically verified identity and a tenant-scoped
  authorization decision. Continue with the middleware guide to apply this to
  every protected route.
</Callout>
