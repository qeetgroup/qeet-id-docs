Qeet ID is a self-hostable identity platform for passkeys-first
authentication, explainable authorization, enterprise federation, and a
tamper-evident audit log.

This portal is the developer documentation. The complete **API reference** lives
separately in Scalar and is linked from the top navigation.

<Callout title="Developer preview">
  Qeet ID is under active development. The Go SDK is available; the Node and
  React clients are source previews awaiting registry publication. Start with
  the Go quickstart, then evaluate the documented platform capabilities.
</Callout>
