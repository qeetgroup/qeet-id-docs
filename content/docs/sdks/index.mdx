Qeet ID's first-party SDKs wrap the API with types, sensible defaults and local
session verification. They are pre-1.0 and release independently.

| SDK | Status | Installation |
| --- | --- | --- |
| Go | **Available** | `go get github.com/qeetgroup/qeet-id-go` |
| Node & TypeScript | **Source preview** | npm release pending |
| React | **Source preview** | npm release pending |

## What the SDKs handle for you

- Zero-config discovery from the issuer URL.
- Local session verification against cached JWKS.
- Typed resources for users, sessions, organizations and permissions.
- Consistent error handling and pagination.
