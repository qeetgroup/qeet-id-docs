Qeet ID is in **active developer preview**. The Go module and documented server
capabilities are available for evaluation; Node and React remain source previews.
This page tracks the path toward general availability.

<Callout type="warn">
  Dates and scope are indicative and will change. Treat the preview as
  production-capable for evaluation, not yet for regulated production workloads.
</Callout>

## Available now

<Steps>

<Step>
### Core identity engine
OIDC provider, users, sessions, organizations, multi-tenancy and passkey-first
signup.
</Step>

<Step>
### Authorization with explainability
RBAC with grant-path explanations via `?explain=true`.
</Step>

<Step>
### Provable audit log
SHA-256 hash-chained events with a public verification endpoint.
</Step>

<Step>
### Go SDK
The pre-1.0 Go module is available from GitHub. Node and React are source
previews pending public npm releases.
</Step>

</Steps>

## On the horizon

- Database-level tenant isolation (Postgres RLS) graduating from pilot.
- Public npm releases for the Node and React clients.
- A `qeetid` CLI (`init` / `dev` / `doctor`).
- Release assurance: external pentest and OpenID conformance run.
- Managed cloud general availability.

<Callout type="info">
  Following along? This page is updated as items ship.
</Callout>
