Whether you're evaluating, self-hosting or building on the managed cloud, here's
how to get unblocked.

## Start with the docs

- **New here?** The [quickstart](/docs/getting-started/quickstart) gets you to a
  working Go integration.
- **Looking for an endpoint?** The full API reference is in Scalar, linked from
  the top navigation.
- **Stuck on a concept?** The [FAQ](/docs/faq) and [concepts](/docs/concepts)
  cover the common questions.

For bugs and feature requests, open an issue on the relevant repository — include
your version, environment (self-hosted or cloud), and steps to reproduce.

## Security

Please report vulnerabilities responsibly — **do not** open a public issue.
Use a GitHub Security Advisory (preferred) or email **security@qeet.in** with the
subject prefix `[SECURITY]`. See [Security](/docs/security) for the disclosure
policy.
