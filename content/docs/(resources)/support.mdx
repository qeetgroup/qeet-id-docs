Whether you're evaluating Qeet ID or building on it, here's how to get unblocked.

## Start with the docs

- **New here?** The [quickstart](/docs/getting-started/quickstart) gets you to a
  working Go integration.
- **Looking for an endpoint?** The full API reference is in Scalar, linked from
  the top navigation.
- **Stuck on a concept?** The [FAQ](/docs/faq) and [concepts](/docs/concepts)
  cover the common questions.

## Community & issues

<Cards>
  <Card title="Email support" href="mailto:support@qeet.in" description="support@qeet.in — questions, bugs and feature requests." />
  <Card title="Roadmap" href="/docs/roadmap" description="What's shipped and what's next." />
</Cards>

For a bug in an SDK, open an issue on its repository —
[Go](https://github.com/qeetgroup/qeet-id-go),
[Node](https://github.com/qeetgroup/qeet-id-node) or
[React](https://github.com/qeetgroup/qeet-id-react). For anything else, email
**support@qeet.in**. Include the SDK or API version and steps to reproduce.

## Security

Please report vulnerabilities responsibly — **do not** open a public issue.
Email **security@qeet.in** with the subject prefix `[SECURITY]`. See [Security](/docs/security) for the disclosure
policy.
