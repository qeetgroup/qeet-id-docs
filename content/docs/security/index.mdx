## Principles

- **Verifiable, not just asserted.** The [audit log](/docs/audit-logs) is
  hash-chained with a public verification endpoint, and every authorization
  decision is [explainable](/docs/authorization/checking-access). You don't have
  to trust the platform — you can check it.
- **Fail closed.** Authorization denies on error; production refuses to boot with
  unsafe configuration.
- **Least privilege.** Agent tokens are short-lived and scope-intersected;
  permissions are fine-grained.

## Reporting a vulnerability

Please report security issues responsibly by email to **security@qeet.in** with
the subject prefix `[SECURITY]` — do not open a public issue. Qeet ID follows a
90-day coordinated-disclosure window and offers safe harbour for good-faith
research.
