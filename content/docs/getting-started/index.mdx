Qeet ID gives your application a complete identity layer — authentication,
authorization, organizations and audit — that you can run yourself or consume
as a managed service. This section starts with the available Go module while
the Node and React packages remain source previews.

## The shape of an integration

Every integration follows the same four moves, regardless of stack:

<Steps>

<Step>
### Install the available SDK
Use the Go module for an executable preview integration. Review the Node and
React source while their npm releases are prepared.
</Step>

<Step>
### Configure a tenant
Create an application in the console and set your API key.
</Step>

<Step>
### Authenticate users
Send users through hosted login (or embed the flow) — passkeys, MFA and SSO
work from day one.
</Step>

<Step>
### Authorize requests
Verify sessions locally and check permissions with explainable RBAC.
</Step>

</Steps>
