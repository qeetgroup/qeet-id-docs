Qeet ID is publishing its SDKs in stages. The Go module is available now. The
Node and React clients are source previews while their first registry releases
are prepared.

<Callout type="warn" title="Preview package status">
  `@qeet-id/node` and `@qeet-id/react` are not published to npm yet. Their pages
  document the intended `0.1` API for review, but do not present an install
  command that would fail. Use the Go module for an executable integration
  today.
</Callout>

## Configure the environment

Your application reads configuration from its environment and passes it to the
SDK. The SDKs do not read these variables implicitly.

```bash title=".env"
QEETID_API_KEY=qk_live_xxxxxxxxxxxxxxxxxxxx
QEETID_BASE_URL=https://api.id.qeet.in
```

<Callout type="info">
  API keys are prefixed `qk_` and sent as `Authorization: ApiKey qk_…`. The SDKs
  add this header after your application passes the key into the client.
</Callout>

<TypeTable
  type={{
    QEETID_API_KEY: {
      description: "Secret API key for your application. Server-side only.",
      type: "string",
      required: true,
    },
    QEETID_BASE_URL: {
      description: "Management API and issuer base URL. Override it for a self-hosted deployment.",
      type: "string",
      default: "https://api.id.qeet.in",
    },
  }}
/>

<Callout type="warn">
  Treat `QEETID_API_KEY` like a password. Keep it out of client bundles and
  version control — load it from a secret manager in production.
</Callout>

## Initialize the Go client

```go title="qeetid.go"
client := qeetid.New(qeetid.Config{
  APIKey:  os.Getenv("QEETID_API_KEY"),
  BaseURL: os.Getenv("QEETID_BASE_URL"),
})
```

For the Node source preview, the equivalent configuration is
`new QeetID({ apiKey, baseUrl })`.

## Verify your setup

A successful install can reach the discovery document:

```bash title="Terminal"
curl "$QEETID_BASE_URL/.well-known/openid-configuration"
```

If that returns JSON with an `issuer` and `jwks_uri`, you're ready for the
[quickstart](/docs/getting-started/quickstart).
