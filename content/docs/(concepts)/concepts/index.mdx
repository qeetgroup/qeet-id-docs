## The object model at a glance

| Object | What it is |
| --- | --- |
| **Organization / tenant** | The top-level isolation boundary. Organization is the SDK-facing term; tenant is the API and storage term. |
| **User record** | A human identity represented inside an organization. |
| **Group** | A team, department or directory group within the organization. |
| **Session** | An authenticated period whose token carries one active organization scope. |
| **Permission** | A fine-grained capability, granted through roles (RBAC). |

<Callout type="info">
  Qeet ID is multi-tenant by default. Even a single-customer deployment runs
  inside one organization boundary, so adding more organizations later does not
  require a different storage or authorization model.
</Callout>
