## The object model at a glance

| Object | What it is |
| --- | --- |
| **Tenant** | The top-level isolation boundary. Every record belongs to exactly one tenant. |
| **User** | A human (or agent) identity within a tenant. |
| **Organization** | A group of users — teams, companies, workspaces — with their own roles. |
| **Session** | An authenticated period, represented by a verifiable token. |
| **Permission** | A fine-grained capability, granted through roles (RBAC). |

<Callout type="info">
  Qeet ID is multi-tenant by default. Even a single-customer deployment runs
  inside one tenant, so scaling to many later requires no re-architecture.
</Callout>
